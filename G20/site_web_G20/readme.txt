# Médias à remplacer

Remplacez les fichiers du dossier \assets\posters par vos versions finales en **gardant exactement les mêmes noms et extensions** :

* **`affiche.jpg`** : la vraie affiche du projet.
* **`bande-annonce.mp4`** : la vidéo définitive.

> Ne modifiez ni le nom ni l'extension, sinon les médias ne s'afficheront pas sur le site.
