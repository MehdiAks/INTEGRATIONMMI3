L'ECHO DU SILENCE — version HTML / CSS / JavaScript

Fichiers principaux :
- index.html : structure et contenu
- style.css : design, responsive et animations CSS
- script.js : clic d'ouverture, navigation, compte à rebours, menu mobile et lecteur vidéo
- images/hero.jpg : visuel principal
- images/affiche.jpg : affiche du film
- videos/ : déposer ici bande-annonce.mp4 si besoin

La section Making of est volontairement un seul accès vidéo. Pour l'utiliser, cliquez sur son bouton et choisissez votre fichier making-of.mp4 depuis l'ordinateur, ou remplacez le bloc par un chemin local vers videos/making-of.mp4.

Lancement local :
1. Ouvrez index.html directement dans Chrome, Edge ou Firefox.
2. Cliquez n'importe où sur la notification du premier écran.
3. Dans la section Bande-annonce, cliquez sur le bouton lecture pour choisir une vidéo depuis votre ordinateur.

Pour remplacer l'affiche ou le visuel principal, conservez les noms hero.jpg et affiche.jpg ou modifiez simplement les chemins dans index.html.

Le contenu, les acteurs, les critiques et la programmation sont fictifs et servent de maquette pédagogique.
